# Extract selected genes from DEGgo rhythmicity results

Extract selected genes from DEGgo rhythmicity results

## Usage

``` r
deggo_extract_rhythmic_genes(results, genes)
```

## Arguments

- results:

  A `deggo_rhythm_results` object returned by
  [`run_deggo_rhythmicity()`](https://ymbouamboua.github.io/DEGgo/reference/run_deggo_rhythmicity.md).

- genes:

  Character vector of gene identifiers.

## Value

A data.frame.
